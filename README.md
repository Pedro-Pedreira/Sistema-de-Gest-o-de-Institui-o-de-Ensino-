
# Sistema de Gestão de Instituição de Ensino

Sistema desenvolvido em Java utilizando Programação Orientada a Objetos (POO), com o objetivo de gerenciar as operações acadêmicas de uma instituição de ensino.

## Sobre o Projeto

O projeto consiste em um sistema de gerenciamento acadêmico que permite organizar informações de cursos, disciplinas, professores, alunos, turmas e matrículas.

Desenvolvido como trabalho final da disciplina de Programação Orientada a Objetos, aplicando conceitos fundamentais da linguagem Java.

## Funcionalidades

- Cadastro de cursos e disciplinas.
- Cadastro de professores.
- Cadastro de alunos regulares e bolsistas.
- Gerenciamento de turmas.
- Realização e gerenciamento de matrículas.
- Lançamento de notas e registro de faltas.
- Cálculo de médias e resultados acadêmicos.
- Cálculo automático de mensalidades.
- Controle de bolsas e descontos.
- Consulta de vagas disponíveis.
- Geração de relatórios acadêmicos.

## Tecnologias Utilizadas

- Java
- Java Swing
- Apache Ant
- ArrayList

## Conceitos de Programação Orientada a Objetos

- Encapsulamento
- Herança
- Polimorfismo
- Abstração
- Interfaces
- Associação, agregação e composição
- Sobrescrita de métodos (`@Override`)

## Como Executar

1. Clone ou baixe este repositório.
2. Abra o Apache NetBeans.
3. Selecione `File > Open Project`.
4. Escolha a pasta do projeto.
5. Execute a aplicação.
